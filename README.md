# HadiFouani.github.io
Personal portfolio showcasing my research, projects, and experience in AI, Machine Learning, and Computer Science.

## Styling

`styles.css` provides an Apple-inspired foundation with system fonts, generous spacing,
rounded cards, blue buttons, visible keyboard focus, and reduced-motion support.
The page automatically follows the visitor's system light/dark preference.

To force a theme, set `<html lang="en" data-theme="light">` or
`<html lang="en" data-theme="dark">` in `index.html`. Remove `data-theme` to
restore automatic selection. Customize the variables at the top of the stylesheet
to adjust colors, spacing, and radii. Optional classes include `.card`, `.grid`,
`.section`, `.eyebrow`, `.muted`, `.button`, and `.button--secondary`.
